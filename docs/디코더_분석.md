## 1. 원본 코드 (Original)

**파일:** `src/models/fit_traffic_model_trans.py`

**특징:** "과거만 보고 미래를 예측하는 모델"
- 디코더 루프 안에서 주변 차량의 **현재 위치**를 참조하지 않음
- Cross-Attention은 오직 **과거 시퀀스(past_seq_out)**에 대해서만 수행

### 1.1 아키텍처 다이어그램

```

├─────────────────────────────────────────────────────────────────┤

│   prev_state (t-1)                                              │
│        │                                                        │
│        ▼                                                        │
│   ┌─────────┐                                                   │
│   │   GRU   │ ◄── cur_state_local (이전 스텝의 로컬 좌표)       │
│   └────┬────┘                                                   │
│        │                                                        │
│        ▼ gru_out (Query)                                        │
│        │                                                        │
│   ┌────┴────────────────────┐                                   │
│   │                         │                                   │
│   ▼                         ▼                                   │
│ ┌───────────────┐    ┌─────────────┐                            │
│ │ Past Cross-   │    │   (없음)    │  ◄── Agent Attention 없음  │
│ │ Attention     │    │             │                            │

│                    └────┬────┘                                  │
│                         │                                       │
```

### 1.2 핵심 코드

#### 모듈 정의 (`__init__`)
```python
# 3-3. Decoder Cross-Attention (Past sequence만 참조)
self.decoder_attention = MultiheadAttention(
    embed_dim=self.gcn_hidden_dim,
    num_heads=decoder_attn_heads,
    batch_first=True
)

# MLP 입력: Agent Attention 없음
decoder_mlp_in_size = (self.gcn_hidden_dim +   # GRU output
                       self.gcn_hidden_dim +   # Past Attention (과거만)
                       self.gcn_hidden_dim +   # Z projection
                       self.map_feat_out_size +
                       self.att_feat_size +
                       self.NC)
self.decoder_output_mlp = MLP([decoder_mlp_in_size, 128, self.traj_out_size])
```

#### 디코더 루프 (`autoregressive_decoder`)
```python
for t in range(FT):
    # 1. GRU (Query 생성)
    gru_input = cur_state_local.unsqueeze(1)  # (B, 1, 4)
    gru_out, cur_mem_state = self.decoder_memory(gru_input, cur_mem_state)
    gru_out = gru_out.squeeze(1)  # (B, D)

    # 2. Cross-Attention (과거 시퀀스에 대해서만!)
    query = gru_out.unsqueeze(1)
    attn_out, _ = self.decoder_attention(
        query=query,
        key=encoder_k_v,    # ◄── past_seq_out (고정!)
        value=encoder_k_v   # ◄── past_seq_out (고정!)
    )
    attn_out = attn_out.squeeze(1)  # (B, D)

    # 3. Output MLP (Agent Attention 없음)
    mlp_in = torch.cat([gru_out, attn_out, z_proj, cur_map_feat, cur_lw, cur_sem], dim=-1)
    decoder_out = self.decoder_output_mlp(mlp_in)

    # ... Bicycle Model ...
```

### 1.3 한계점

- **문제:** `encoder_k_v = past_seq_out`는 디코딩 루프 시작 전에 고정됨
- **결과:** 매 스텝에서 다른 차량의 **현재 위치**를 볼 수 없음
- **의미:** t=5에서 옆 차량이 내 쪽으로 접근해도, 모델은 t=0 시점의 과거 정보만 참조

## 2. 수정된 코드 (Modified)

**파일:** `src/models/traffic_model_trans_decoder_changed.py`

**특징:** "과거도 보고, 현재 주변 상황도 매 순간 살피는 리액티브 모델"
- **Agent Cross-Attention** 추가
- 매 스텝마다 다른 차량들의 **현재 위치**를 Query하여 참조

### 2.2 핵심 코드

#### 모듈 정의 (`__init__`) - 추가된 부분
```python
###########################################################################
# HJ_ADDED: Agent Cross-Attention for Future Interaction
###########################################################################
# This module enables agents to see other agents' current positions during
# future trajectory decoding (autoregressive step).
# - Query: Current agent's GRU hidden state
# - Key/Value: Other agents' current states (position + heading)
###########################################################################
self.agent_state_encoder = MLP([4, 64, self.gcn_hidden_dim])  # (x,y,hx,hy) -> D
self.agent_cross_attention = MultiheadAttention(
    embed_dim=self.gcn_hidden_dim,
    num_heads=decoder_attn_heads,
    batch_first=True
)
###########################################################################

# MLP 입력 크기 변경: Agent Attention 추가
decoder_mlp_in_size = (self.gcn_hidden_dim +   # GRU output
                       self.gcn_hidden_dim +   # Past Attention
                       self.gcn_hidden_dim +   # Agent Cross-Attention [NEW!]
                       self.gcn_hidden_dim +   # Z projection
                       self.map_feat_out_size +
                       self.att_feat_size +
                       self.NC)
```

#### 디코더 루프 (`autoregressive_decoder`) - 추가된 부분
```python
for t in range(FT):
    # 1. GRU (Query 생성) - 동일
    gru_input = cur_state_local.unsqueeze(1)
    gru_out, cur_mem_state = self.decoder_memory(gru_input, cur_mem_state)
    gru_out = gru_out.squeeze(1)

    # 2. Past Cross-Attention - 동일
    query = gru_out.unsqueeze(1)
    attn_out, _ = self.decoder_attention(query=query, key=encoder_k_v, value=encoder_k_v)
    attn_out = attn_out.squeeze(1)

    ###########################################################################
    # HJ_ADDED: Agent Cross-Attention for Future Interaction
    ###########################################################################
    # 현재 시점의 모든 에이전트 위치 가져오기
    if t == 0:
        all_agents_pos = scene_graph.past[:, -1, :4]  # (NA, 4)
    else:
        all_agents_pos = prev_state[:, :4]  # (bsize, 4) - 이전 스텝 출력!

    # 위치를 피처로 인코딩
    all_agents_feat = self.agent_state_encoder(all_agents_pos)  # (bsize, D)

    # 모든 에이전트가 서로를 볼 수 있도록 K/V 구성
    agent_kv = all_agents_feat.unsqueeze(0).expand(NA, NA, -1)  # (NA, NA, D)

    # Agent Cross-Attention
    agent_query = gru_out.unsqueeze(1)  # (bsize, 1, D)
    agent_attn_out, _ = self.agent_cross_attention(
        query=agent_query,
        key=agent_kv,      # ◄── 현재 시점의 다른 차량들!
        value=agent_kv
    )
    agent_attn_out = agent_attn_out.squeeze(1)  # (bsize, D)
    ###########################################################################

    # 3. Output MLP - agent_attn_out 추가!
    mlp_in = torch.cat([
        gru_out,
        attn_out,
        agent_attn_out,    # ◄── [NEW!] 다른 차량 정보
        z_proj,
        cur_map_feat,
        cur_lw,
        cur_sem
    ], dim=-1)
    decoder_out = self.decoder_output_mlp(mlp_in)

    # ... Bicycle Model ...
```

### 2.3 개선점

| 원본 | 수정 |
|------|------|
| K/V가 `past_seq_out` 고정 | K/V가 매 스텝 `prev_state`로 업데이트 |
| 과거 정보만 참조 | 과거 + 현재 주변 차량 위치 참조 |
| Open-loop 예측 | Closed-loop / Reactive 예측 |
| 충돌 회피 불가 | 실시간 충돌 회피 가능 |

## 3. 슬라이드 모델 (Slide Model)

**특징:** "출발 전에 모든 계획을 다 짜놓고 실행만 하는 모델"
- Temporal Self-Attention으로 **전체 미래 Planning Features를 한번에 생성**
- GRU + Bicycle은 pre-computed features를 순차 실행만 함

### 3.1 아키텍처 다이어그램

```
┌─────────────────────────────────────────────────────────────────┐
│              Pre-computation Phase (Before Loop)                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   [z, map, past, sem] ──► Temporal Self-Attention               │
│                                    │                            │
│                                    ▼                            │
│                    O = [o₁, o₂, ..., o_FT]  (Planning Features) │
│                    ▲                                            │
│                    │ 한번에 전체 시퀀스 생성 (고정!)             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Decoder Loop (t = 1 to FT)                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   prev_state (t-1)                                              │
│        │                                                        │
│        ├───────────────────┐                                    │
│        ▼                   ▼                                    │
│   ┌─────────┐        ┌──────────┐                               │
│   │   GRU   │ ◄──────│ o_t      │ (미리 계산된 Planning Feature)│
│   └────┬────┘        └──────────┘                               │
│        │                                                        │
│        ▼                                                        │
│   ┌─────────┐         (별도 Attention 없음 - o_t에 다 들어있음) │
│   │   MLP   │                                                   │
│   └────┬────┘                                                   │
│        │                                                        │
│        ▼                                                        │
│   ┌──────────────┐                                              │
│   │ Bicycle Model│                                              │
│   └──────┬───────┘                                              │
│          │                                                      │
│          ▼                                                      │
│    cur_state (t)                                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 개념적 흐름 (슬라이드 기반)

```
Phase 1: Feature Generation (한번에)
═══════════════════════════════════════
Feature(Repeated) = [z^i, m^i_{t-1}, s^i, b^i]
         │
         ▼
   Temporal Self-Attention
         │
         ▼
   O^i = [o^i_1, o^i_2, ..., o^i_{T_f}]  ◄── 전체 미래 계획


Phase 2: Autoregressive Execution (순차)
═══════════════════════════════════════
for t = 1 to T_f:
    g^i_t = [y^i_t, o^i_t]   ◄── pre-computed o_t 사용
         │
         ▼
       GRU
         │
         ▼
    c^i_t (control)
         │
         ▼
    Bicycle Model
         │
         ▼
    y^i_{t+1}
```

### 3.3 한계점

- **문제:** `O = [o₁, ..., o_FT]`가 t=0에서 한번에 생성되어 고정됨
- **결과:** t=5에서 주변 상황이 바뀌어도 `o₅`는 이미 결정되어 있음
- **의미:**
  - 학습 시에는 GT future로 Attention하므로 long-range dependency 학습 가능
  - 추론 시에는 다른 차량의 미래를 모르므로 반응 불가

## 4. 핵심 차이점 비교

### 4.1 정보 흐름 비교

| 구분 | 원본 | 수정 | 슬라이드 |
|------|------|------|----------|
| **K/V 소스** | `past_seq_out` (고정) | `past_seq` + `prev_state` (동적) | `O` (pre-computed, 고정) |
| **Agent 정보** | t=0 시점만 | 매 스텝 현재 위치 | t=0 시점만 |
| **반응성** | 없음 | 있음 | 없음 |
| **루프 내 계산** | Past Attention | Past + Agent Attention | GRU + Bicycle만 |

### 4.2 MLP 입력 비교

```python
# 원본 (fit_traffic_model_trans.py:437)
mlp_in = torch.cat([gru_out, attn_out, z_proj, cur_map_feat, cur_lw, cur_sem], dim=-1)
#                   ───────  ────────  ──────  ───────────  ──────  ───────
#                     (D)      (D)      (D)       (64)        (2)     (NC)

# 수정 (traffic_model_trans_decoder_changed.py:527)
mlp_in = torch.cat([gru_out, attn_out, agent_attn_out, z_proj, cur_map_feat, cur_lw, cur_sem], dim=-1)
#                   ───────  ────────  ──────────────  ──────  ───────────  ──────  ───────
#                     (D)      (D)         (D)          (D)       (64)        (2)     (NC)
#                                          ▲
#                                     [NEW!] 다른 차량 현재 위치
```

### 4.3 계산 복잡도

| 구분 | 원본 | 수정 | 슬라이드 |
|------|------|------|----------|
| **루프당 Attention** | O(PT) | O(PT) + O(NA) | 없음 |
| **전체 복잡도** | O(FT × PT) | O(FT × (PT + NA)) | O((NA×T)²) + O(FT) |
| **메모리** | 낮음 | 중간 | 높음 (pre-compute) |

## 5. 결론

### 5.1 왜 수정이 필요했나?

**원본 코드의 문제:**
```
t=0: "과거 4초를 보고 계획을 세웠어"
t=5: "계획대로 직진 중..." (옆 차가 갑자기 끼어들어도 무시)
t=8: 💥 충돌
```

**수정 코드의 해결:**
```
t=0: "과거 4초를 보고 계획을 세웠어"
t=5: "잠깐, 옆 차가 가까워지네?" (Agent Attention으로 감지)
     → "살짝 회피하자" (MLP가 agent_attn_out 보고 판단)
t=8: ✅ 안전하게 통과
```

### 5.2 슬라이드 모델은 왜 안 되나?

- **학습 장점:** 전체 시퀀스에 Attention → long-range dependency 학습에 유리
- **추론 한계:** 다른 차량의 미래 위치를 모르므로 Planning Features가 부정확
- **적대적 시나리오:** Sur 차량이 공격해도 Ego는 t=0에 세운 계획대로만 움직임

### 5.3 최종 비유

| 모델 | 비유 |
|------|------|
| **원본** | 눈을 감고 과거 기억만으로 운전 |
| **수정** | 눈을 뜨고 실시간으로 주변을 살피며 운전 |
| **슬라이드** | 출발 전 네비 경로 설정 후 중간에 수정 없이 그대로 따라감 |
